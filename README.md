# FitnessClub

Первая лабораторная работа по дисциплине **«Разработка корпоративных приложений»**.

## Описание

Разработана объектно-ориентированная модель предметной области фитнес-клуба и набор unit-тестов для работы с тестовыми данными.

Основные сущности:

* `Client` — клиент фитнес-клуба;
* `Trainer` — тренер;
* `Specialization` — специализация тренера;
* `Hall` — зал;
* `Booking` — бронирование тренировки;
* `Gender` — пол клиента или тренера (человека).

Для тестирования используется набор данных, содержащий клиентов, тренеров, залы, специализации и бронирования.

## Тесты

Реализованы LINQ-запросы и unit-тесты для:

* поиска тренеров со стажем от 5 лет;
* поиска клиентов с просроченным абонементом;
* определения 5 самых популярных тренеров;
* проверки занятости зала;
* получения занятий выбранного зала за текущий месяц.

## Запуск

Требуется **.NET 10**.

```bash
cd FitnessClub
dotnet test
```

Тесты автоматически запускаются через **GitHub Actions** при изменениях в лабораторных ветках.
